# Brooklyn Morning — project instructions

Personal iPhone PWA for Paolo: morning edition (news + one daily lesson), fast to-do capture, Trader Joe's grocery list, NCAA men's water polo results (2026, with team screens, conference tables and the CWPA Top 20), Library. Full approved spec: `SPEC.md`. Progress and continuation point: `STATUS.md` — update it at the end of every work session.

## Hard rules (never relax)
- **Zero additional cost.** Only free, non-metered services: GitHub Pages + Actions on a public repo, Open Food Facts, public RSS feeds, SEC (`data.sec.gov`, EDGAR, Financial Statement Data Sets), Nasdaq Trader, Massive/Polygon "Stocks Basic" (free key, no payment method, blocks rather than bills), OSS packages. No paid/metered AI APIs at build or run time, no free trials, no billing-enabled infrastructure. If a free service stops, keep data and fall back to cache — never route around it with a paid one.
- **Privacy.** `about-me.md` and any personal file must never be committed or deployed (`.gitignore` covers it). No employer or student records. Personal data lives only in the browser's IndexedDB (`personal` DB). Dev fixtures under `fixtures/` load only with `?fixtures=1` on localhost.
- **No advertising, tracking, analytics, affiliate links, or monetization.**
- **News honesty.** Never fabricate stories, quotes, or links. Publisher excerpts are labeled "From publisher"; build-time extracted lead paragraphs are labeled "Opening of the article"; the app never rewrites or claims to have read an article. No paywall circumvention. Freshness labels always show the edition's real date. A saved story's reading view shows the app's own stored summary and says so; "Read original article" is the only path to the publisher's text.
- **Refresh honesty.** "Complete" is only shown once a **newly built** file has been downloaded, validated, saved **and** put on screen. A run that finished green without publishing a new `builtAt` read nothing and is reported as such — never as "no changes found". Re-downloading the same published file is a fetch, not a refresh. Partial coverage is never reported as "all schools". A manual run must never be routed through the cron's once-per-slot guard, and must never claim one of its slots.
- **Fixture honesty.** A game becomes `final` only when a source publishes a score — never because its start time has passed; an elapsed fixture reads "Awaiting result". A start time is labelled ET only where a source makes its zone certain; otherwise it is the venue's local time, and a missing time says "Time TBD".
- **Lesson honesty.** Week boundaries are decided in America/New_York. Every week ships a 20-question quiz before its Sunday (the build fails otherwise). An archived edition shows the lesson that date actually carried, resolved from the fixed date-to-week mapping and pinned with its pack version; today's lesson is never substituted in.
- **One school, one identity.** Two spellings merge only on evidence: the same verified athletics hostname *and* compatible printed names, decided before any game is matched. Never on a matching score, date or logo, and never by name alone across different schools ("Concordia Irvine" is not every Concordia).
- **Results honesty (water polo).** Never invent or infer a score. A missing score is never 0-0. Season is pinned to 2026 and re-validated on every fetch. When two official pages disagree, show one row and either the result an official box score settles (with the link) or nothing at all — never an average, never two rows. Freshness must state how many of the 13 schools were actually read. A game is a **conference game only when the CWPA's own conference schedule lists that fixture** — never because both teams share a conference. The conference table is Paolo's own 3-points-per-win calculation and must always say so; **poll points are copied from the CWPA and never computed**. An opponent's page is only believed once it names 2026 men's water polo and lists a game that team is already known to have played.
- **Source permission.** Only sources whose terms or robots.txt allow automated use. Yahoo Finance is **not permitted** (`User-agent: * / Disallow: /`) and was removed on 2026-10-06; so are Stooq, api.nasdaq.com, data.nasdaq.com and Twelve Data. The SEC requires a declared contact (`SEC_CONTACT`); a false one would misrepresent the requester, so the build fails without it. Secrets stay in Actions and never reach the browser.
- **Stock honesty.** The score on a card is a **ranking position among that day's eligible candidates**, never a probability, price target or forecast — and the card says so next to the number. Fundamentals are read as they stood on the decision date (`accepted ≤ T`), never as they read today. A signal a company cannot have is **dropped and the remaining weights renormalised**, never scored zero; a company that should report revenue and does not is ineligible. Trailing-year figures are four single quarters, never a mixed set of durations. Returns are total returns, with dividends restated across splits. Entry is the open of the first session *after* publication; the entry session is day 1 of 21. Only **completed** positions enter an average. Thresholds are published and are never relaxed to fill a card — an empty card says which test bound. A pick belongs to the session it was made in and is never republished as fresh. Version 1's records are kept exactly as published and never merged with version 2's.
- **Never silently weaken a feature.** If something can't be done at zero cost, say so and record it in `STATUS.md`.

## Stack
Vite + Preact + TypeScript · `vite-plugin-pwa` (Workbox) · IndexedDB via `idb` (separate `personal` and `catalog` databases) · Vitest (+ fake-indexeddb, jsdom) · Playwright (iPhone viewports 375/393/430) · Node scripts in `scripts/` (edition build, catalog build, icons) · GitHub Actions cron for the daily edition.

## Layout
- `src/` app code (`ui/` components, `screens/`, `db/`, `lib/` pure logic, `styles/`)
- `public/logos/` team crests, downloaded once by `scripts/fetch-logos.mjs` (never hotlinked at runtime)
- `public/data/` edition, editions archive, lessons, glossary, catalog, water polo feed, CWPA poll (generated + authored data)
- `scripts/` Node build scripts · `tests/` Vitest · `e2e/` Playwright · `fixtures/` dev fixtures
- `state/` build-time state (seen URLs, price-bar cache `state/bars/<year>/<date>.csv.gz` append-only, SEC digests `state/sec/*.csv.gz`, pick logs)

## Conventions
- Pure logic (ranking, cleanup, discovery rules, validators) lives in `src/lib/` and is unit-tested.
- Every IndexedDB write is one transaction; catalog is validated before replacing the previous one.
- Copy for the UI is plain English, concise. Labels must not overstate ("Prepared 5:52 AM", "From yesterday", "Source unavailable today").
- Commit messages: short imperative subject; no personal info.

## Commands
`npm run dev` · `npm run build` · `npm test` · `npm run e2e` · `npm run build:edition` · `npm run build:stocks` (`--dry-run`, `--sec-only`, `--backfill=N`) · `npm run backtest:stocks` · `npm run build:catalog` · `npm run build:waterpolo` (`--dry-run`, `--school=<id>`, `--no-opponents`, `--no-conference`) · `npm run build:poll` (`--dry-run`, `--url=<article>`) · `npm run build:lessons` · `npm run logos` · `npm run icons`
